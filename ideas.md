# Boolean Circuit Lab — Design Directions

## Approach A — Blueprint Workshop

**Theme Name:** Blueprint Workshop  
**Very Brief Intro:** A precise electronics workbench inspired by technical drafting paper, copper traces, and laboratory instrumentation. It makes Boolean analysis feel tangible and methodical rather than abstract.  
**Probability:** 0.07

## Approach B — Analogue Signal

**Theme Name:** Analogue Signal  
**Very Brief Intro:** A warm editorial interpretation of computing, using ink-black text, muted paper, and rich amber signal indicators. It presents logic as a readable argument rather than a dense control panel.  
**Probability:** 0.04

## Approach C — Circuit Atlas

**Theme Name:** Circuit Atlas  
**Very Brief Intro:** A disciplined modernist technical atlas with off-white surfaces, dark graphite lettering, and a vivid teal used only where a signal is active. It is designed to make transformation, validation, and flow instantly legible.  
**Probability:** 0.09

# Chosen Direction — Circuit Atlas

## Design Movement

**Swiss modernism meets scientific-technical illustration.** The interface uses clear asymmetry, systematic rules, and generous breathing room so that a potentially complex Boolean transformation reads like a well-made instrument panel.

## Core Principles

1. **Signal before decoration:** Outputs, connections, and validation states use the clearest visual hierarchy.
2. **Calm precision:** Surfaces are restrained and high contrast; every line, gap, and label has a structural role.
3. **Traceable transformation:** Inputs, simplified logic, and physical gate implementations form an obvious reading path.
4. **Useful density:** Technical detail remains available without turning the interface into a crowded dashboard.

## Color Philosophy

Warm blueprint paper and graphite establish trust, focus, and a tactile technical feel. A deep blue-green (**Signal Teal**) identifies active computational states, selected input methods, correct verification, and signal lines. Copper-orange is reserved for warnings and noteworthy intermediate states, making status readable without relying on color alone.

## Layout Paradigm

The page behaves like a **technical workbench**: a narrow left rail contains input and action controls, while a broad right canvas presents results in a vertical evidence trail. On small screens the workbench folds into sequential field sections, preserving the same input-to-proof order.

## Signature Elements

1. **Signal trace:** A fine teal line with circular junctions connects output cards and appears as a repeating visual language.
2. **Drafting labels:** Uppercase micro-labels and monospaced equation text annotate the interface like a circuit sheet.
3. **Instrument blocks:** Results sit in subtly shadowed, square-leaning panels with a slim colored status rule.

## Interaction Philosophy

Controls acknowledge input immediately and the Analyze action makes the evidence trail appear in order. Tabs and toggles feel like selecting modes on laboratory equipment: direct, tactile, and highly legible. The design never obscures a technical result behind visual flourish.

## Animation

Use short 140–220ms ease-out transitions for tab changes, button presses, focus states, and result reveals. Circuit nodes can fade in along a path after analysis, but all motion respects reduced-motion preferences. No continuous decorative animation is used.

## Typography System

**Space Grotesk** provides the geometrical display hierarchy for headings and control labels. **IBM Plex Mono** is used for equations, minterms, variables, truth-table data, and gate annotations. Body text uses Space Grotesk at a relaxed line-height. Headings use tight tracking; drafting labels use uppercase wide tracking.

## Brand Essence

**Boolean Circuit Lab turns a Boolean rule into verified, buildable logic for learners, engineers, and curious makers.**  
Personality: **exact, approachable, evidence-led**.

## Brand Voice

Headlines are confident, instructional, and concrete. CTAs use direct verbs and labels describe what happens next. Avoid vague, motivational filler.

> “Turn a truth condition into a circuit you can inspect.”

> “Analyze function — simplify, synthesize, verify.”

## Wordmark & Logo

The mark is a bold teal **split-node circuit glyph**: three orthogonal traces converge on a circular output node, suggesting an AND/OR decision point without using text. The wordmark pairs the geometric name with a small monospaced “LAB” label.

## Signature Brand Color

**Signal Teal — #007C74.** A deep, ownable active-state color used for valid logic, focused controls, and circuit signal paths.
