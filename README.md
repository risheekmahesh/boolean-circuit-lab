# Digital Circuits Lab

An interactive Boolean-function and digital-circuit analysis tool.

## Features

- Boolean expression analysis
- Truth table generation
- Minterm and maxterm input
- Karnaugh map simplification
- Standard circuit visualization
- NAND-only circuit implementation
- NOR-only circuit implementation
- Interactive circuit diagrams
- AI-assisted digital circuit problem solving

## Technologies

- TypeScript
- JavaScript
- Python
- React
- Vercel

## Project

This project is designed to help students analyze Boolean functions and understand their corresponding digital circuit implementations.
